
# 번역 문구 관리

CSV에는 저장·삭제 확인, 사용 방법, 오류 안내처럼 내용을 이해해야 하는 문구만 둡니다. **PLAY, EDIT, OPTIONS, Save, BPM, SR** 같은 짧은 UI 이름과 수치 표기는 영어 그대로 사용합니다. 판정 문구 **JUST+, JUST, GOOD, OK, NAH, MISS**와 곡 제목·유저명도 번역하지 않습니다.

## 번역 적용

1. 프로젝트의 `translations/messages.csv`를 엽니다.
2. `ko` 열에 번역을 입력합니다. 다른 언어는 `ja`, `de`, `fr`, `zh_CN` 등의 언어 코드로 열을 추가합니다.
3. **CSV UTF-8, 쉼표 구분**으로 저장합니다.
4. 게임을 실행하고 **Options → System → Language**에서 언어를 선택합니다.
5. 게임을 다시 시작합니다. 빈 번역은 영어로 표시되며, 번역이 하나도 없는 언어는 선택 목록에 표시되지 않습니다.

현재 게임은 프로젝트에 포함된 CSV만 사용합니다. 게임 내 번역 파일 가져오기·내보내기 및 외부 번역 파일 적용 기능은 제공하지 않습니다. 배포판에 변경 사항을 반영하려면 수정한 CSV를 포함해 다시 빌드합니다.

| 열                | 용도                                                                                     |
| ----------------- | ---------------------------------------------------------------------------------------- |
| `keys`          | `ERROR_CHART_OPEN_FAILED`, `CONFIRM_SAVE_CHART` 같은 고정 식별자. 수정하지 않습니다. |
| `en`            | 영어 기본 문구. 번역할 때는 그대로 둡니다.                                               |
| `ko`, `ja` 등 | 해당 언어의 번역. 빈 칸은 기본 문구를 사용합니다.                                        |
| `notes`         | 사용 위치와`%s`, `%d` 등의 표기 안내. 게임에는 표시되지 않습니다.                    |

첫 두 열은 `keys,en`이어야 합니다. `%s`, `%d`, `%.2f`, `%%`는 종류·개수·순서를 유지합니다. 예를 들어 `Failed to open chart file: %s`는 `차트 파일을 열지 못했습니다: %s`로 번역할 수 있습니다. 실제 줄바꿈은 유지하며 문자 `\n`으로 바꾸지 않습니다.

`en`에는 기본 영어 문구가 필요합니다. CSV에는 enum에 등록된 키만 사용할 수 있으며, PLAY나 판정 문구를 임의로 추가해도 번역되지 않습니다.

## 문구 추가·수정

`global/game_text.gd`의 `GameText.Key` enum과 `translations/messages.csv`를 직접 관리합니다. 자동 수집이나 별도 갱신 명령은 없습니다.

새 안내 문구는 enum에 의미가 드러나는 이름을 추가하고 CSV의 `keys`에도 같은 이름을 넣습니다. 코드에서는 `GameText.text(GameText.Key.ERROR_CHART_OPEN_FAILED) % path`처럼 사용합니다. 씬의 Label이나 대화상자에는 `CONFIRM_SAVE_CHART` 같은 키를 지정하면 Godot 자동 번역이 적용됩니다. 영어 문장을 다듬을 때는 `en`만 변경하고 키는 유지합니다.

파일명, API 식별자, 차트 데이터에는 번역을 사용하지 않습니다. OS 파일 선택창의 기본 문구와 외부 서버가 직접 보내는 오류는 OS·서버에서 제공됩니다.

배포에는 `messages.csv.import`의 `keep` 설정과 내보내기의 `translations/*.csv` 필터로 원본 CSV를 포함합니다.
